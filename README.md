本项目基于开源JSONView进行修改

- 修改了各个属性(如String、Num、Bool等)的颜色
- 字体进行了稍许放大
- 增加了json代码层级虚线
- 可以右键复制key和value，以及key的json路径了
- 增加json块hover突出显示
- 增加了设置界面，以上所有可以自定义设置
